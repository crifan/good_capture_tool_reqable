# 二级代理

## 什么是二级代理

二级代理是指Reqable将捕获的流量转发给另一个代理服务器（如翻墙代理）处理。

工作流程：

```
（iOS或Android等移动端的）App -> Reqable -> （Mac等电脑端的）二级代理 -> 目标服务器
```

## 为什么需要二级代理

* 问题背景
  * 系统只能配置一个代理，当Reqable作为系统代理时：
    * 翻墙代理（如Android中的Clash、iOS中的Shadowrocket等）被冲突掉了=无法正常工作（继续翻墙）
      * -》导致app端需要访问外网的请求会失败
* 解决方案
  * 配置二级代理后：
    * 数据流程变成
      * （移动端的）Reqable捕获流量
      * 将需要翻墙的流量转发给（电脑端的）二级代理=此二级代理，往往是另外一个翻墙软件的代理，可以翻墙
  * 效果
    * 实现（往往是电脑端和移动端协同）抓包和（app端的）翻墙同时工作
