# Reqable简介

## 什么是Reqable

`Reqable`是一款新一代抓包工具（和API调试），功能类似`Charles`和`Fiddler`，但功能更好用，UI界面更好看。

## 主要特点

* 功能好用，界面好看
  * 界面上各种显示细节做的很好
  * 还有很多细节的功能，对于抓包工具来说很实用
* 其他
  * **跨平台支持**：支持Windows、macOS、Linux、Android、iOS等多个平台
  * **现代化界面**：基于Flutter开发，界面简洁美观
  * **协同模式**：支持PC端与移动端协同抓包
  * **二级代理**：内置二级代理功能，解决翻墙代理冲突问题
  * **App过滤**：支持仅抓取特定App的流量
  * **高性能**：底层采用高性能技术栈，抓包流畅

## 与其他工具对比

### 与Charles对比

| 特性 | Reqable | Charles |
|------|---------|---------|
| 界面风格 | 现代化 | 传统 |
| 移动端协同 | 原生支持 | 需配置 |
| 二级代理 | 内置 | 需第三方 |
| App过滤 | 内置 | 不支持 |
| 价格 | 较低 | 较高 |

### 与mitmproxy对比

| 特性 | Reqable | mitmproxy |
|------|---------|-----------|
| 界面 | GUI | 命令行/Web |
| 上手难度 | 简单 | 中等 |
| 脚本扩展 | 有限 | 强大 |
| 移动端App | 有 | 无 |
