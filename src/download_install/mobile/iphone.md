# iPhone

此处介绍，iPhone中，如何安装Reqable：

AppStore中，搜素：`Reqable`：

![reqable_appstore_download](../../assets/img/reqable_appstore_download.jpg)

点击下载安装，显示：打开

![reqable_appstore_open](../../assets/img/reqable_appstore_open.jpg)

桌面上即可出现Reqable图标了：

![reqable_iphone_desktop](../../assets/img/reqable_iphone_desktop.jpg)

然后去打开：

![reqable_iphone_accept_agreement](../../assets/img/reqable_iphone_accept_agreement.jpg)

首次启动，会询问你工作模式，默认是：`协同模式（推荐）`==电脑端和移动端协同工作一起抓包 = 移动端抓包+电脑端查看

![reqable_iphone_mode_cowork](../../assets/img/reqable_iphone_mode_cowork.jpg)

继续，进入主页
